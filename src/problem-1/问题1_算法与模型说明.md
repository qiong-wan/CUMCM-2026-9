# 问题 1 算法与模型说明

本文档说明 `src/problem-1/solve_problem1.py` 实际采用的物理模型与数值算法，与代码一一对应，供复现和后续问题扩展使用。公式推导详见 `问题1_解题框架与公式推导.md`。

## 1. 问题与几何

把中药材视为半径 $R=0.02\ \mathrm m$、长度 $L=0.25\ \mathrm m$ 的圆柱体，取轴线为 $r=0$、外表面为 $r=R$。只研究预热平衡阶段 $0\le t\le1800\ \mathrm s$，且只求沿半径方向的分布，因此采用一维轴对称模型。初始温度 $T_0=28\ {}^\circ\mathrm C$，初始干基含水率 $C_0=2.55\ \mathrm{kg/kg}$。

烘房温度 $T_\infty(t)$ 与烘房水分浓度 $C_\infty(t)$ 取自 `data/附件1.xlsx`（每 60 s 一个观测，覆盖 0--14400 s）。在 $0\le t\le1800$ s 内按分段线性插值构造连续边界，插值严格通过原始观测点。

## 2. 控制方程与边界条件

### 2.1 温度场

物性取常数，Fourier 定律给出圆柱坐标下的非稳态导热方程

$$
\rho c_p\frac{\partial T}{\partial t}
=\frac{1}{r}\frac{\partial}{\partial r}\left(kr\frac{\partial T}{\partial r}\right),
\qquad 0<r<R,
$$

$$
\left.\frac{\partial T}{\partial r}\right|_{r=0}=0,
\qquad
-k\left.\frac{\partial T}{\partial r}\right|_{r=R}=h\,[T(R,t)-T_\infty(t)],
\qquad
T(r,0)=28.
$$

### 2.2 水分场

干基含水率 $C$ 满足浓度相关扩散方程

$$
\frac{\partial C}{\partial t}
=\frac{1}{r}\frac{\partial}{\partial r}\left[rD(C)\frac{\partial C}{\partial r}\right],
\qquad 0<r<R,
$$

$$
\left.\frac{\partial C}{\partial r}\right|_{r=0}=0,
\qquad
-D(C)\left.\frac{\partial C}{\partial r}\right|_{r=R}=h_m\,[C(R,t)-C_\infty(t)],
\qquad
C(r,0)=2.55,
$$

$$
D(C)=7\times10^{-9}\exp\!\left(-\frac{0.89}{C}\right)\quad(\mathrm{m^2/s}).
$$

### 2.3 参数（附录 2）

| 参数 | 数值 | 单位 |
|---|---|---|
| 密度 $\rho$ | 820 | $\mathrm{kg/m^3}$ |
| 比热容 $c_p$ | 2600 | $\mathrm{J/(kg\cdot K)}$ |
| 导热系数 $k$ | 0.36 | $\mathrm{W/(m\cdot K)}$ |
| 对流换热系数 $h$ | 25 | $\mathrm{W/(m^2\cdot K)}$ |
| 对流传质系数 $h_m$ | $8\times10^{-7}$ | $\mathrm{m/s}$ |

热扩散率 $\alpha=k/(\rho c_p)=1.6886\times10^{-7}\ \mathrm{m^2/s}$。$1800$ s 时热 Fourier 数 $Fo_T\approx0.76$，传质 Fourier 数 $Fo_{M,0}\approx0.022$，热 Biot 数 $Bi_T\approx1.39$，初始传质 Biot 数 $Bi_{M,0}\approx3.24$。两个 Biot 数均明显大于 0.1，故内部梯度不可忽略，必须求解偏微分方程而不能用集总参数法。

### 2.4 模型简化

- 温度场与水分场解耦：题面未给出汽化潜热、吸附等温线或热湿耦合系数，故不在能量方程中加入蒸发潜热项。
- 半径固定为 2 cm，不使用附件 2 的收缩数据（附件 2 属于问题 4）。
- 只取一维径向，忽略轴向梯度与端面换热；端面仅占外表面积的 $R/(L+R)\approx7.4\%$，且 1800 s 内的热、湿特征扩散长度均远小于半长 12.5 cm。
- 烘房水分浓度被当作经验有效传质势，与药材干基含水率的差值作为传质推动力；题面未给出平衡含水率关系。

## 3. 数值方法

### 3.1 空间离散：节点中心有限体积

在均匀网格 $r_i=i\,\Delta r$（$i=0,\dots,N$，$\Delta r=R/N$）上采用节点中心有限体积法。对内部控制体，界面取 $r_{i\pm1/2}=r_i\pm\Delta r/2$，体积与面积（已约去公共因子 $\pi L$）为

$$
V_i=\frac{A_{i+1/2}}{2}r_{i+1/2}-\dots,\qquad
A_{i\pm1/2}=2r_{i\pm1/2}.
$$

中心节点为半径 $\Delta r/2$ 的半控制体，表面节点为 $[R-\Delta r/2,\,R]$ 的半控制体，外表面面积 $A_R=2R$。把温度与水分统一写成

$$
sV_i\frac{\mathrm du_i}{\mathrm dt}
=A_{i+1/2}\Gamma_{i+1/2}\frac{u_{i+1}-u_i}{\Delta r}
-A_{i-1/2}\Gamma_{i-1/2}\frac{u_i-u_{i-1}}{\Delta r}
+(\text{表面节点对流项}),
$$

其中温度场 $(s,\Gamma)=( \rho c_p,k)$，水分场 $(s,\Gamma)=(1,D(C))$。水分扩散系数在界面上取相邻控制体值的调和平均

$$
D_{i+1/2}=\frac{2D(C_i)D(C_{i+1})}{D(C_i)+D(C_{i+1})},
$$

以保证界面通量连续。中心对称条件使中心控制体只有东侧通量；表面控制体的对流项为 $A_RH[u_\infty(t)-u_N]$。

### 3.2 时间离散：后向 Euler

采用一阶隐式后向 Euler，子步长 $\Delta t=1/\text{nsub}=0.025$ s，每 1 s 抽样一次输出。温度方程为线性三对角系统，每步只需一次带状求解；水分方程因 $D(C)$ 非线性，采用 Picard 定点迭代：用上一步迭代的 $C$ 计算界面扩散系数，组装并求解三对角系统，直至相邻迭代最大变化小于 $10^{-12}$。若达到 60 次仍未收敛则抛出异常并报告残差与迭代次数。三对角系统统一用 `scipy.linalg.solve_banded` 求解。

### 3.3 计算网格与交付网格

- 交付网格：题目要求的 $0,0.1,\dots,2.0$ cm，共 21 个节点。
- 计算网格：$N_{\text{ref}}=1600$ 个控制体（$\Delta r=0.00125$ cm），即每个交付节点间含 80 个细控制体。结果在细网格上求解后按整数步长抽样到交付节点。

细网格是必要的：表面含水率在初始阶段存在很薄的高梯度层（特征厚度约 $\sqrt{Dt}$，1 s 时约 0.07 mm），粗网格的表面半控制体平均会带来明显偏差。收敛性检验表明，加密计算网格时含水率场最大差按约二阶收敛。

## 4. 算法流程

```
读取并审计附件1 -> 构造 T_inf(t), C_inf(t) 分段线性插值
初始化 T=C=初值
for sec = 1..1800:
    for sub = 1..nsub:
        Tinf, Cinf = 插值(当前子步时刻)
        解温度三对角系统 -> T
        Picard 迭代解水分三对角系统 -> C   (容差 1e-12, 上限 60)
    记录该秒的温度、含水率场及守恒/边界诊断量
抽样到 0.1 cm 交付节点 -> 写出 result1.xlsx、表1、表2
运行验收检查 -> 写出 verification.txt
```

## 5. 验证

程序内置以下检查，并在 `output/problem-1/verification.txt` 记录结果；硬阈值不通过时程序直接失败。

- 输入审计：列数、缺失/非数值、时间严格递增（无重复）、覆盖 $[0,1800]$ s。
- 整体守恒：离散总热量、总水量的变化与累积边界通量之相对误差均要求 $<10^{-4}$。
- Picard 收敛：每步必须收敛，记录最大迭代次数与最大残差。
- 表面 Robin 残差：用二阶单侧差估计表面梯度，检查温度、水分边界残差。
- 物理趋势：结果有限、温度处于 $[28,42]\,{}^\circ\mathrm C$、含水率处于 $[0,2.55]$；温度随半径不减、含水率随半径不增；表面温度随时间不减、表面含水率随时间不增。
- 网格/时间收敛（`--verify`）：相邻加密网格与时间步下交付节点的最大差。

当前生产结果（$N_{\text{ref}}=1600$，$\Delta t=0.025$ s）的验证摘要：

| 指标 | 数值 |
|---|---|
| 热量守恒相对误差 | $9.7\times10^{-6}$ |
| 水分守恒相对误差 | $6.1\times10^{-6}$ |
| Picard 最大迭代次数 / 残差 | 4 / $5.8\times10^{-15}$ |
| 表面温度 Robin 残差 | $1.1\times10^{-4}\ \mathrm{W/m^2}$ |
| 表面水分 Robin 残差 | $8.0\times10^{-10}$ |
| 物理趋势检查 | 通过 |

空间收敛（交付节点最大差）：$N=400\to800$ 为 $8.2\times10^{-4}\ \mathrm{kg/kg}$，$N=800\to1600$ 为 $1.9\times10^{-4}\ \mathrm{kg/kg}$，主要出现在最初几秒的表面节点；$t\ge100$ s 后该差已小于 $6\times10^{-5}\ \mathrm{kg/kg}$。时间收敛（$N=200$）：$\text{nsub}=40\to80$ 为 $6.5\times10^{-5}\ \mathrm{kg/kg}$，$\text{nsub}=80\to160$ 为 $3.3\times10^{-5}\ \mathrm{kg/kg}$。因此交付表格对应时刻的结果已基本网格无关，最初 1--2 s 的表面值仍带约 $10^{-4}$ 量级的离散不确定度。

## 6. 运行方法

```bash
# 依赖: Python 3.11+, numpy, scipy, openpyxl
python src/problem-1/solve_problem1.py            # 生成结果、表1/表2、验证
python src/problem-1/solve_problem1.py --verify   # 额外输出网格/时间收敛
```

输出：

- `output/problem-1/result1.xlsx`：工作表 `温度`、`水分浓度`，A1 为 `时间\到药材中心的距离`，A 列为 $1\sim1800$ s，首行为 $0\sim2$ cm（步长 0.1 cm），数值格式 `0.0000`。
- `output/problem-1/table1_temperature.csv`、`table2_moisture.csv`：论文表 1、表 2。
- `output/problem-1/verification.txt`：验收检查记录。

## 7. 局限与后续

- 温度结果未计入蒸发潜热，水分结果是题给经验传质模型下的数值预测；二者解耦是题面参数不足下的基线处理。
- 烘房水分浓度与药材干基含水率之差被直接当作传质推动力，并非严格相平衡浓度差。
- 一维径向忽略端面效应；若需研究端部，应扩展为 $r$-$z$ 二维轴对称模型。
- 问题 2 及以后将引入随温度、含水率变化的物性、耦合传热传质与尺寸收缩，本问模型作为其基础。
