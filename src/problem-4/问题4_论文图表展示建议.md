## 3. 可以新增的图表

以下项目是建议，尚未生成。它们可使用既有案例后处理完成，不需要重新运行 PDE。

| 建议 | 数据来源 | 展示价值及限制 |
|---|---|---|
| 达标体积比例随时间变化 | 主案例各时刻含水率全场、当前半径和圆柱体积权重 | 比平均含水率更直接地描述已有多少体积低于 0.15；需按未舍入阈值判断，注明是数值体积比例，不是实测成品率 |
| 高含水率核心的实际半径曲线 | 每个保存时刻的 0.15 等值位置 | 与外半径并列可显示仍未达标的内部范围；该位置只是阈值定义的核心边界，不是物理相变界面 |
| 相同实际距离与归一化距离的剖面对照 | 已保存场和实测半径 | 区分几何收缩造成的位置变化与含水率分布形状变化；两个横轴必须分别写清实际 cm 和归一化坐标 |
| 情景结果汇总表 | 各情景 metadata.json 及已有验证记录 | 列出物性、几何、环境延拓、达标时长或覆盖终点状态；未达标情况写“72 h 内未达标”，不能把 72 h 当作临界时长 |
| 紧凑的误差与验证表 | 既有空间、时间、边界和守恒记录 | 可替代正文中的完整 06 图；应分别列出相邻解差、事件定位和守恒缺陷，不合并为单一“真实误差” |

目前没有潜热耦合、二维端面、非均匀收缩、新环境漂移等情景的求解结果，因此不能绘制这些因素对应的“时长修正对照图”。密度或条件性潜热预算可以作为模型限制的诊断表，但不能冒充新物理模型的验证结果。

## 4. 可直接使用的图注

**图 04：** 实测收缩条件下药材干基含水率的时空演化。纵轴为距轴线的实际距离，红线为实测半径插值得到的表面位置，灰色区域位于药材外部。白色虚线为 0.15 kg/kg 等值线，按保存的数值场重构；干燥终点仍由未舍入全域最大含水率判据确定。

**图 06：** 第四问空间与时间分辨率核对。两组分别固定时间倍率和径向网格，以各自最细级计算结果为参考展示时长绝对差，红圈标出主方案采用的网格或时间倍率。下表给出相邻加密级的全场含水率差、温度差、临界时长差及原验收状态。参考解自差为零，观察收敛阶与相邻差均不构成连续解或实际工艺的误差保证。

## 5. 排版和重绘

- 04 和含表格的 06 适合通栏排版；03、05 可按子图拆分。统一字体和量纲，不将图中显示位数当作物理精度。
- 论文排版优先使用 SVG 矢量文件；需要位图时使用同时导出的 320 dpi PNG。04 的色场在 SVG 中栅格化，文字、边界和等值线仍保留矢量表达。
- 06 若在缩小后表格字号过小，可在论文中把下方验收表排成独立表格；当前一体版便于直接检查图表对应关系。
- 每张图给出一个明确结论，正文不必同时放入所有已有图。四情景时长差不具有普遍可加性，情景区间也不是统计置信区间。

在 Solution 项目根目录，只重绘本轮两组图的命令为：

```powershell
python -B -X utf8 src/problem-4/generate_figures.py --require-verified --figures 04_moisture_space_time 06_numerical_convergence
```

不指定 figures 时保留原有全部绘图流程。选择性重绘会保留其他图及各自生成源码指纹，当前绘图清单逐图记录来源，不能把保留的旧图声称为由新源码重新生成。
